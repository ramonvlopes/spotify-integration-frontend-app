# Screens

## English

Top-level page components, one per route. They compose containers and components into a full page layout and are responsible for the overall page structure.

### Rules
- Screens are thin — they define layout and pass route params down
- Business logic lives in containers, not screens
- Each screen lives in its own CamelCase folder

### Examples
`ArtistListScreen`, `ArtistDetailScreen`, `FavoritesScreen`

---

## Português

Componentes de página de nível superior, um por rota. Compõem containers e componentes em um layout de página completo.

### Regras
- Screens são finas — definem layout e passam params de rota para baixo
- Lógica de negócio fica nos containers, não nas screens
- Cada screen fica em sua própria pasta CamelCase

### Exemplos
`ArtistListScreen`, `ArtistDetailScreen`, `FavoritesScreen`
